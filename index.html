Case 002 · RAG system · Sports analytics

A RAG system that answers basketball questions, and shows its work.

RAG means the AI looks things up in real data before it answers, instead of answering from memory. I built one for a full basketball season: 800+ games, every player's stats, the game stories and the injury reports. You ask a question in plain English. It finds the answer and shows exactly where it came from. If the data can't answer, it says so instead of guessing.

  1. 01Code finds the who and the when.Player names, teams and dates are matched exactly. Nothing is guessed.
  2. 02The database does the math.Adding, counting and sorting happen in code, so the numbers are always right.
  3. 03AI only reads the writing.It reads one injury note or one game story, then code double checks what it found.

Most AI chatbots guess at numbers. This one can't, because the AI never does the math.
